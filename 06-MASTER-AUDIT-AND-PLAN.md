## 4. THE MISSING FOUNDATIONS (build these first — nothing else compounds without them)

### 4.1 Email list + lead capture (HIGHEST PRIORITY)
- Pick one ESP (recommend **MailerLite or ConvertKit** — free tiers handle this scale, creator-friendly).
- Replace/upgrade the WPForms Lite flow so every submission is **stored + piped to the ESP + auto-responded.**
- Add **3 lead magnets**, one per audience:
  - *Parents/Local:* "5 Phrases That Calm a Frustrated Kid (from 25 years on the mat)" or free chapter of *Grapple with Emotions*.
  - *Coaches:* "The Kids BJJ Class Blueprint" (a sample curriculum/lesson plan PDF — he already has the DVD content).
  - *Adults:* free *Boundary Guard* module / "Why You Freeze" mini-guide.
- Each lead magnet → tagged segment → simple nurture sequence → relevant offer (free class / Skool / Boundary Guard).
- **Result:** books, podcast, IG, YouTube, and inquiries finally convert into an owned, segmentable audience.

### 4.2 Unified brand system (visual cohesion)
- One **logo, color palette, typography, and template kit** applied across every surface.
- Current state: academy site uses Inter/DM Sans, navy/blue/green; DVD store and podcast site are visually unrelated. Pick ONE system and roll it out.
- Build a **1-page brand guide** + reusable social templates (Canva) so every post looks unmistakably "Joao Crus."
- **Fix the typos** site-wide — a copy pass is cheap and immediately raises perceived quality.

### 4.3 Content engine (one idea → many assets)
- Joao already writes excellent long-form (Skool posts, blog). The problem is distribution, not creation.
- Install a **repurposing flywheel**: 1 podcast episode/week → transcript → blog post → 3 IG reels/carousels → 1 email → 1 YouTube clip. (He's already recording; we systematize the output.)
- **Consistency beats volume.** Commit to a sustainable cadence (e.g., 1 podcast + 3 IG + 1 email per week) and hold it. The 14-month podcast gap is the single biggest momentum-killer to eliminate.
