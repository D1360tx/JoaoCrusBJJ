# AI Search Plan

> Objective: make Joao Crus BJJ easy to identify, understand, trust, and cite in Google AI Overviews, ChatGPT search, Perplexity, Bing/Copilot, Gemini, and other answer engines.

## What earns visibility

AI search is built on normal search fundamentals. The priorities are:

1. Crawlable, indexable HTML on the primary domain
2. Clear entities and relationships
3. Firsthand experience and named expertise
4. Specific answers that can stand alone outside the page
5. Accurate structured data
6. Original media and source links
7. Independent third-party corroboration

`llms.txt` is supplemental. It does not replace these foundations.

## First content cluster to build

### Hub: Parent guide

Canonical page: `/parent-guide/`

Build it into a genuinely useful resource, not a lead-capture shell. It should answer first-class questions directly and link to age-specific programs.

### Supporting resources

1. **What Age Can Children Start Brazilian Jiu-Jitsu?**
   - Explain age readiness without claiming every child is the same.
   - Include Joao's firsthand teaching perspective.
   - Cite preschool movement research only for outcomes it actually supports.

2. **What Tapping Teaches a Young Child**
   - Use Kaiden's story as clearly labeled firsthand parent experience.
   - Explain that tap communicates stop and that partners must respect it.
   - Do not imply that tapping eliminates injury risk.

3. **What Happens in a BJJ Class for Ages 3-7?**
   - Short activities, movement, simple language, games, parent visibility, and safe boundaries.
   - Use original academy photography or video.

4. **How to Choose a Kids BJJ Program by Age**
   - Compare ages 3-7, 8-12, and 13-17 in a structured table.
   - Link to each canonical program page.

5. **First BJJ Class Checklist for Parents**
   - Clothing, arrival, hygiene, watching, hesitation, and questions to ask.
   - Make the checklist visible in HTML and downloadable secondarily.

## Guardrails

- Do not turn every question into a thin page.
- Do not keyword-stuff location names.
- Do not invent statistics, outcomes, credentials, prices, reviews, or schedule details.
- Do not represent one family's story as a guaranteed result.
- Do not use research about general movement programs as proof that BJJ causes a specific outcome.
- Do not add FAQ, Review, or AggregateRating schema unless it accurately matches visible content and platform eligibility.
