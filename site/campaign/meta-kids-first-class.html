Parent questions

BEGINNER QUESTIONS ARE WELCOME HERE.

Does my child need experience?

No. A first-ever sport or first time on the mat is a normal starting point. The finder asks about experience so the academy can respond appropriately.

Does the program finder book or charge anything?

No. It sends a request for a recommendation and next-step guidance. A class is not automatically booked and no payment is collected.

Which locations offer kids programs?

Dripping Springs offers Little Champions ages 3–7 and Youth ages 8–12. Austin currently offers Youth ages 8–12. Teen options require confirmation.

What if I have more than one child?

The finder supports multiple children and can return a family-level recommendation covering every applicable age group.
