# Joao Crus BJJ Ads Swipe File

A working library of paid ads and landing pages Diego wants to study for Joao Crus BJJ offer development.

## How to add a swipe

Send the ad screenshot or video plus its destination URL. Each entry should preserve:

1. The original creative asset.
2. Source, placement, date captured, and available campaign parameters.
3. Exact visible ad copy.
4. Landing-page copy and funnel structure.
5. Offer stack, pricing, bonuses, proof, objections, and CTA path.
6. Message match between the ad and landing page.
7. Patterns worth testing for Joao, without copying competitor language or claims.
8. Open questions and validation needs.

Use [`_entry-template.md`](_entry-template.md) for future entries. Historical snapshots belong under `raw/<slug>/<YYYY-MM-DD>/` so changes can be compared without overwriting prior research.

## Working taxonomy

- **Audience:** toddler parent, youth parent, teen parent, adult beginner, private coaching, coach/school, corporate
- **Offer:** lead magnet, trial, deposit-credit intro, course, membership, private package, event
- **Angle:** confidence, safety, simplicity, identity, authority, speed, structure, belonging, transformation
- **Creative:** founder portrait, class footage, testimonial, demonstration, listicle, before/after, offer card
- **Funnel:** awareness, lead capture, direct purchase, booking, application, retargeting

## Evaluation rule

A swipe is inspiration, not validation. We still require Joao-specific economics, operational fit, claim safety, and conversion tracking before adapting a pattern into a live offer.
