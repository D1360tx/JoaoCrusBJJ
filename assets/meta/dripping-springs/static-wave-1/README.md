## Reproduce

From the repository root:

```sh
python assets/meta/dripping-springs/static-wave-1/render.py
python assets/meta/dripping-springs/static-wave-1/validate.py
```

Requires Pillow 12.3.0 and licensed Impact/Arial host fonts at the paths recorded in the manifest. Fonts are not redistributed. `DISPLAY_FONT` and `BODY_FONT` can override paths, but byte-identical results require the exact recorded font hashes and renderer environment. No random seed, timestamps, network requests or generative APIs are used. Run twice and compare SHA-256 to verify deterministic output.

The script validates two outputs, dimensions, source/output hashes, actual text/logo/photo containment, pairwise non-overlap and public copy recommendations (125/40/30 characters). Vertical conservative bounds reserve top 270, bottom 410 and right 180 pixels; native Feed/Stories/Reels previews remain required before upload approval. The full source frame is retained without a crop or AI edits. Hashes identify files, not participant releases.
